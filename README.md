# Animated Globe Login Page

A stunning, interactive login page featuring a 3D animated globe, liquid glassmorphism UI, water ripple effects, and a secure dashboard redirect.

## Features

- **3D Animated Globe** — Rotating particle sphere with 500 dots, connection lines, depth sorting, pulsing particles, and mouse-reactive tilt
- **Liquid Glassmorphism Login Card** — Frosted glass effect with blur, liquid shine sweep, reflection, and floating animation
- **Water Ripple Effects** — Click anywhere to create water ripples; auto-ripples appear on the background
- **Eyebrow-Style Password Toggle** — Custom animated eye with eyebrow that opens/closes when showing/hiding password
- **Liquid Glass Button** — Hover triggers liquid fill, shine sweep, and floating particle effects
- **Card 3D Tilt** — The login card tilts based on mouse position for a parallax effect
- **Staggered Dashboard Animations** — Smooth entrance transitions with liquid glass frame after successful login
- **GitHub Profile Link** — Quick access to the developer's profile

## File Structure

```
├── index.html          # Main login page with animated globe & liquid glass
├── style.css           # Liquid glass styles, water effects, and animations
```

## How to Use

1. Download all files into the same folder.
2. Ensure `after-login-image.jpg` is placed in the same directory.
3. Open `index.html` in your browser.
4. Type the username and password from the table above.
5. Click the **Sign In** button to access the dashboard.
